# Codeforces 4A — Watermelon

Source: <https://codeforces.com/problemset/problem/4/A>

Implement `canSplitEven(weight: Int): Boolean`.

## Domain

`1 <= weight && weight <= 100`.

## Result

Return `true` exactly when `weight` can be expressed as the sum of two positive
even integers. Equivalently, the result is true exactly when `weight` is even and
strictly greater than `2`.

## Verification target

Prove the equivalence in the result clause for every value in the domain. The
solution should not perform console I/O.
