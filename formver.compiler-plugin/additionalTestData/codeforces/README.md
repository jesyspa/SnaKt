# Codeforces problem briefs

These briefs adapt competitive-programming tasks into small, pure Kotlin
functions suitable for SnaKt. Console input/output is intentionally outside the
verification target. Statements below are paraphrases; follow the linked
originals for attribution and contest context.

## Selected tasks

- `734A-anton-and-danik.md`: a single-pass character-count comparison.
- `41A-translation.md`: a positional check that one string reverses another.
